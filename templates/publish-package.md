## Título — 12 candidatos, 4 eixos

Escreva três por eixo antes de escolher. Os eixos vêm do `brand-kit/COPY_STYLE.md` —
**não existe eixo de urgência aqui**, porque "faça isso antes que seja tarde" está na lista de
recusados da marca. O gancho cria uma lacuna precisa de informação; não fabrica pânico.

| Eixo | O que é | Candidatos |
|---|---|---|
| Lacuna | a pergunta que o vídeo responde, sem entregar a resposta | 1. <br>2. <br>3. |
| Número | o dado que ancora o episódio | 1. <br>2. <br>3. |
| Tensão | "parece X até você olhar para Y" | 1. <br>2. <br>3. |
| Implicação | o que muda para quem assiste | 1. <br>2. <br>3. |

Limite prático: ~60 caracteres antes do corte na busca; o essencial nos primeiros 40.

## Thumbnail — 3 variantes, decidida por medição

Gere as três variantes nos dois formatos (1280×720 e 1080×1920). São **três** porque o
"Testar e comparar" do YouTube compara no máximo três. Confira que nenhuma linha estoura a margem e
que a arte de origem não é menor que o alvo.

| Variante | Eixo | Texto | Arquivo 16:9 | Arquivo 9:16 |
|---|---|---|---|---|
| a |  |  |  |  |
| b |  |  |  |  |
| c |  |  |  |  |

Escolha um padrão editorial e registre a hipótese de cada alternativa. Quando elegível, use o
teste nativo de até três títulos, thumbnails ou pares. O resultado considera tempo de exibição;
poucas impressões podem deixá-lo inconclusivo. Não declarar vencedora por opinião ou por
trocas manuais sequenciais. Shorts não participam do teste nativo.
[Documentação conferida em 13/09/2026](https://support.google.com/youtube/answer/16391400?hl=pt-BR).
